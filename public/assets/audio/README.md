# Nhạc nền — bỏ file vào đây

| File | Dùng cho | Gợi ý |
|------|----------|-------|
| `bg-music.mp3` | Nhạc nền (bật bằng nút 🔊) | MP3, nên < 3–4MB, có thể cắt 1–2 phút loop |

Tên phải khớp `theme.music` trong `src/assets/config/wedding.config.ts`.
Khách bấm nút 🔊 để phát (trình duyệt chặn tự phát khi mới vào).
